# Diseños de cintillos

Guarda aquí los archivos PNG de los diseños para OBS.

- Usa nombres descriptivos, por ejemplo: `evento-2026.png`.
- Para conservar transparencia, exporta el PNG desde Photoshop con fondo transparente.
- Usa una imagen en la resolución del lienzo de OBS (por ejemplo, 1920 × 1080) y coloca el diseño del cintillo dentro del lienzo.
- Cuando subas una imagen, podrás usar su URL pública de GitHub en el control.
